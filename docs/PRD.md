## 1. 개요

아이디어 한 줄을 넣으면 질문 5\~10개로 빈 곳을 채운 뒤, 클로드 코드에 바로 넣을 수 있는 PRD, 단계별 작업 체크리스트, CLAUDE.md 초안을 만들어 주는 웹 서비스다.

**해결할 문제.** 비전공 바이브코더는 GPT·클로드에 "PRD 써줘"라고 요청한다. 그러면 질문 없이 문서가 바로 나오고, 매번 형식이 다르며, 결제·탈퇴·권한 같은 구멍은 개발 중반에야 드러난다. PRD를 받아도 코딩 AI에 어떤 순서로 넣어야 할지 모른다.

**제품 원칙.**

- 문서보다 질문이 먼저다. 사용자가 생각 못 한 부분을 질문으로 끌어낸다.
- 결과물은 사람이 읽는 문서가 아니라 클로드 코드가 읽는 입력이다.
- 개발 용어에는 항상 한 줄 풀이를 붙인다.

**성공 지표 (출시 후 3개월)**

| 지표 | 목표 |
| --- | --- |
| 가입자 | 500명 |
| 질문 인터뷰 완료율 (시작 대비) | 60% 이상 |
| 결과물 다운로드·복사율 (생성 대비) | 70% 이상 |
| 유료 결제 사용자 | 100명 |
| 월 매출 | 100만 원 |
| 문서 1세트당 AI 원가 | 500원 이하 |

## 2. 타깃 사용자와 핵심 시나리오

1순위는 클로드 코드·커서로 SaaS를 1\~3개 만들어 보고 한 번쯤 중간에 무너져 본 비전공자다.

| 우선순위 | 페르소나 | 지금 하는 방식 | 원하는 것 |
| --- | --- | --- | --- |
| 1 | 바이브코딩 2\~3회차 비전공자 | GPT·클로드에 매번 PRD를 새로 요청 | 빠뜨린 게 없는 PRD, 클로드 코드에 넣는 순서 |
| 2 | 사이드 프로젝트 하는 기획자·마케터 | 노션에 기획서를 직접 작성 | 기획서를 개발 가능한 형태로 바꾸기 |
| 3 | 바이브코딩 강의 수강생 | 강사가 준 템플릿 사용 | 강의에서 바로 쓰는 표준 PRD |

**핵심 시나리오 (1순위 사용자 기준)**

1. 주말 사이드 프로젝트로 "동네 헬스장 출석 체크 앱"을 떠올리고 서비스에 한 줄을 입력한다.
2. 서비스가 "출석은 누가 찍나요? 회원 본인 / 관장님 / 둘 다" 같은 질문을 대화로 하나씩 묻고, 답할 때마다 아이디어를 요약해 보여준다.  직접 작성 이외에 AI가 직접 추천하는 질문을 위에 둔다.&#32;
3. 모든 질문이 끝나면 AI가 "더 넣고 싶은 기능이나 고칠 부분이 있나요?"라고 최종 확인하고, 반영이 끝나면 PRD가 나온다.&#32;
4. 크레딧 1건을 결제하고 작업 단계 12개와 CLAUDE.md를 연다.
5. 세 파일을 내려받아 프로젝트 폴더에 넣고, 1단계 프롬프트부터 클로드 코드에 붙여 넣는다.

## 3. MVP 범위

MVP는 기능 3개만 만든다. 결제는 구현이 쉬운 건당 크레딧으로 시작하고, 월 구독은 결제 데이터가 쌓인 뒤 v1.1에서 붙인다.

| 구분 | 기능 | 비고 |
| --- | --- | --- |
| 포함 | F1. 대화형 아이디어 인터뷰 (최종 확인 포함) | 개발 공수의 대부분을 여기에 쓴다 |
| 포함 | F2. PRD + 작업 단계 + CLAUDE.md 생성·내보내기 | .md 다운로드와 복사 |
| 포함 | F3. 로그인, 프로젝트 저장, 크레딧 결제 | 구글·카카오 로그인, 토스페이먼츠 일반결제 |
| v1.1 | 월 구독 (정기결제) | 크레딧 구매 패턴 확인 후 |
| v1.1 | 기능 추가 시 PRD 업데이트 | 재방문 장치 |
| 나중 | 팀 협업, 템플릿 마켓, 노션 연동, 와이어프레임 생성, 버전 비교, 영어 지원 | 지금 만들지 않는다 |

**개발 전 검증.** F1은 구글폼과 수작업으로 먼저 10명에게 돌려 보고, 질문 세트를 다듬은 뒤 개발한다.

## 4. 기능 상세 요구사항

### F1. 대화형 아이디어 인터뷰

클라이언트와 상담하듯 대화로 아이디어를 완성하고, 마지막에 추가·수정 사항을 확인한 뒤에 PRD를 만든다.

- **첫 화면:** 클로드의 첫 화면 UI를 참고한다. 화면 가운데에 인사말 "어서오세요"와 "어떤 아이디어를 만들어볼까요?", 그 바로 아래에 대화 입력창 하나만 둔다. 로그인 없이 바로 입력할 수 있다.
- **입력창 옵션:** 입력창 아래에 예시 아이디어 칩 3개(누르면 입력창에 채워짐), 입력창 옆에 사용할 도구(기본값: 클로드 코드)와 코딩 경험 선택 버튼. 고르지 않아도 진행된다.
- **말투:** 실제 클라이언트를 대하는 기획자처럼 친절하고 쉬운 존댓말. 개발 용어는 쓰지 않거나 바로 풀어 쓴다.
- **대화 흐름 (답변마다 반복):**
  1. 사용자가 쓴 내용을 2\~3줄로 요약해 보여준다. 예: "정리해 보면, 헬스장 회원이 출석을 직접 찍고 관장님이 한눈에 확인하는 앱이네요."
  2. 아직 비어 있는 영역 중 가장 중요한 것을 질문 1개로 묻는다.
  3. 질문 아래, 직접 입력창 위에 AI가 추천하는 답변 2\~3개를 버튼으로 보여준다. 사용자는 추천 답변을 누르거나, 직접 쓰거나, "잘 모르겠어요 (추천해 주세요)"를 누른다.
- **점검 영역 9개:** 대상 사용자, 핵심 문제, 핵심 기능, 사용자 흐름, 저장할 데이터, 로그인·권한, 결제, 외부 연동, 디자인 톤.
- **아이디어 요약 패널:** 지금까지 정리된 아이디어를 항목별로 보여주고 대화가 진행될 때마다 갱신한다. PC는 오른쪽, 모바일은 상단 접이식.
- **완성 판단:** 9개 영역이 채워지거나 질문이 10개에 도달하면 완성. 최소 5개는 묻는다.
- **최종 확인:** 완성되면 전체 요약을 보여주고 "더 넣고 싶은 기능이나 고치고 싶은 부분이 있나요?"라고 묻는다. 답하면 요약에 반영해 다시 보여준다. "이대로 PRD 만들기" 버튼을 누를 때까지 몇 번이든 반복할 수 있다.
- 대화는 매번 저장해 중간에 나가도 이어서 할 수 있다.

**완료 기준**

- [ ] 첫 화면에는 인사말 두 줄과 입력창만 보이고, 로그인 없이 입력할 수 있다.
- [ ] AI의 모든 응답이 "요약 → 질문 1개 → 추천 답변" 순서를 지킨다.
- [ ] 같은 아이디어라도 답에 따라 다음 질문이 달라지고, 질문은 10개를 넘지 않는다.
- [ ] PRD 생성 전에 반드시 추가·수정 사항을 묻는 최종 확인을 거친다.
- [ ] 질문 하나가 화면에 뜨기까지 3초 이내(스트리밍).

### F2. 문서 생성과 내보내기

인터뷰가 끝나면 문서 3개를 탭으로 보여준다.

- **PRD (고정 목차):** 개요, 대상 사용자, 핵심 기능(필수 / 있으면 좋음 / 나중), 사용자 흐름, 화면 목록, 데이터 구조, 추천 기술 스택, 만들지 않을 것, 미결 사항.
- **작업 단계:** 8\~15단계. 각 단계 = 목표 한 줄 + 클로드 코드에 붙여 넣을 프롬프트 + 완료 확인 방법. 체크박스로 진행 표시.
- **CLAUDE.md 초안:** 프로젝트 개요, 기술 스택, 작업 규칙(한 번에 한 단계만, 수정 전 계획 먼저 설명 등).
- 인터뷰에서 답하지 않은 영역은 PRD의 "미결 사항"에 자동으로 들어간다.
- 각 문서에 복사 버튼과 .md 다운로드, 세 파일 한 번에 받기(zip).
- 섹션 단위 "다시 쓰기": 크레딧 1건당 3회까지.
- 크레딧이 없으면 PRD만 열리고, 작업 단계와 CLAUDE.md는 흐린 미리보기 + 결제 버튼으로 보인다.

**완료 기준**

- [ ] 생성 중 글자가 실시간으로 나타난다(스트리밍).
- [ ] 내려받은 .md를 클로드 코드에 넣었을 때 1단계 프롬프트가 그대로 실행 가능하다.

### F3. 로그인, 저장, 결제

- 구글·카카오 로그인. 로그인은 인터뷰가 끝나고 문서를 만들기 직전에 요구한다(입력 전 이탈 방지).
- 내 프로젝트 목록: 이름, 만든 날짜, 상태(인터뷰 중 / 완료). 클릭하면 결과 화면으로 이동.
- 크레딧 결제: 토스페이먼츠 일반결제. 결제 성공 시 크레딧 지급, 문서 열람 시 1건 차감.
- 가입 시 무료 크레딧은 주지 않는다. 대신 무료로 PRD는 항상 볼 수 있다.

**완료 기준**

- [ ] 결제 성공 웹훅이 오기 전에는 크레딧이 지급되지 않는다.
- [ ] 같은 결제가 두 번 처리되지 않는다.

아이디어 대화는 요약과 질문을 반복하며 완성되고(5\~10문항), 최종 확인에서 추가·수정 사항을 받은 뒤 문서를 만든다. 크레딧이 없으면 PRD만 열린 채 결제로 이어진다.

| 화면 | 경로 | 주요 요소 |
| --- | --- | --- |
| 첫 화면 | `/` | 인사말 "어서오세요" + "어떤 아이디어를 만들어볼까요?", 그 아래 대화 입력창, 예시 칩, 도구·경험 선택 (클로드 첫 화면 참고) |
| 아이디어 대화 | `/p/[id]/chat` | 대화창(AI 요약 + 질문 + 추천 답변 버튼), 직접 입력창, 아이디어 요약 패널, 진행 표시 |
| 최종 확인 | `/p/[id]/chat` (같은 화면) | 전체 요약, 추가·수정 입력, "이대로 PRD 만들기" 버튼 |
| 결과 | `/p/[id]` | 탭 3개(PRD / 작업 단계 / CLAUDE.md), 복사·다운로드, 잠금 미리보기 |
| 내 프로젝트 | `/projects` | 프로젝트 목록, 상태, 이어하기 |
| 크레딧 | `/credits` | 남은 크레딧, 1건·5건 결제 |
| 약관·개인정보 | `/terms`, `/privacy` | 이용약관, 개인정보처리방침 |

## 6. 데이터 구조

테이블은 5개로 시작한다. 모든 테이블은 Supabase RLS(행 단위 보안: 자기 데이터만 읽고 쓰게 막는 규칙)를 켠다.

| 테이블 | 주요 컬럼 | 설명 |
| --- | --- | --- |
| profiles | id (auth 사용자 id), nickname, credits (정수, 기본 0), created\_at | 사용자 정보와 남은 크레딧 |
| projects | id, user\_id, idea, tool, experience, status (interviewing / final\_check / done), coverage (json: 9개 영역 상태), summary (json: 최신 아이디어 요약), unlocked (bool), created\_at | 아이디어 1개 = 프로젝트 1개 |
| messages | id, project\_id, role (ai / user), content, options (json), phase (interview / final\_check), created\_at | 대화 기록 |
| documents | id, project\_id, kind (prd / tasks / claude\_md), content (markdown), rewrite\_count, updated\_at | 생성된 문서 3종 |
| payments | id, user\_id, order\_id (고유), amount, credits\_added, status, toss\_payment\_key, created\_at | 결제 기록. order\_id 고유 제약으로 중복 처리 방지 |

크레딧 변경은 서버(API 라우트)에서만 한다. 브라우저에서 credits 컬럼을 직접 수정할 수 없게 RLS로 막는다.

## 7. 기술 스택과 AI 설계

클로드 코드가 가장 잘 다루고 자료가 많은 조합을 고른다. 서버를 따로 두지 않고 Next.js API 라우트 하나로 끝낸다.

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 프레임워크 | Next.js (App Router) + TypeScript | 화면과 서버 API를 한 프로젝트에서 처리 |
| 스타일 | Tailwind CSS + shadcn/ui | 디자인 지식 없이 깔끔한 화면 |
| DB·로그인 | Supabase (Postgres, Auth) | 구글·카카오 로그인 기본 제공, 무료 플랜으로 시작 |
| AI | Anthropic API (Claude) | 질문은 빠르고 싼 모델, 문서는 상위 모델 |
| 결제 | 토스페이먼츠 (일반결제) | 국내 카드·간편결제, 테스트 모드 제공 |
| 배포 | Vercel | GitHub 연결만으로 배포 |

**AI 호출은 두 종류다.**

1. **대화 응답 만들기** (`/api/chat`)
   - 입력: 아이디어, 도구, 경험 수준, 지금까지의 대화, 9개 영역 상태, 현재 단계(interview / final\_check).
   - 출력: 화면에 보여줄 메시지(요약 + 질문, 스트리밍)와 별도 데이터 `summary` (항목별 아이디어 요약), `coverage` (영역별 상태), `options` (추천 답변 0\~3개), `phase` (다음 단계). 한 번의 호출에서 도구 호출 형식으로 함께 받는다.
   - 말투 규칙: 클라이언트를 상담하는 기획자처럼 친절한 존댓말, 매번 요약 먼저, 질문은 하나만, 개발 용어는 풀어 쓰기, 이미 답한 내용 반복 금지.
   - 단계 규칙: 5문항 전에는 완성 판단 금지, 10문항째에는 무조건 final\_check로. final\_check에서는 추가·수정 사항만 묻고 요약을 갱신한다.
2. **문서 만들기** (`/api/documents/generate`)
   - 입력: 대화 전체 기록과 최종 확인을 거친 아이디어 요약.
   - 출력: PRD, 작업 단계, CLAUDE.md 세 개를 각각 고정 목차의 마크다운으로. 스트리밍으로 화면에 표시.
   - 규칙: 답하지 않은 영역은 지어내지 말고 "미결 사항"으로. 최종 확인에서 받은 추가·수정 사항은 반드시 반영. 작업 단계의 각 프롬프트는 단독으로 붙여 넣어도 실행되게.

프롬프트 원문은 `lib/prompts/` 폴더에 파일로 두고 코드와 분리한다. 질문 품질을 고칠 때 이 파일만 수정하면 된다.

**미결 사항:** 모델별 실제 건당 원가는 MVP 테스트 10건으로 측정해 확정한다.

## 8. 요금제와 결제 정책

MVP는 무료 PRD + 건당 크레딧 두 가지로만 판다.

| 플랜 | 가격 | 제공 | 시기 |
| --- | --- | --- | --- |
| 무료 | 0원 | 인터뷰 무제한, PRD 열람·복사 | MVP |
| 크레딧 1건 | 3,900원 | 프로젝트 1개의 작업 단계 + CLAUDE.md 열람, zip 다운로드, 다시 쓰기 3회 | MVP |
| 크레딧 5건 | 14,900원 | 위 혜택 5개 프로젝트분 | MVP |
| 월 구독 | 9,900원 | 무제한 열람, 다시 쓰기 무제한 | v1.1 |
| 교육 라이선스 | 수강생 1인당 5,000원/기수 | 강사용 코드로 일괄 지급 | 수동 판매 |

- 크레딧은 프로젝트를 "잠금 해제"할 때 1건 차감된다. 한 번 해제한 프로젝트는 계속 열람 가능.
- 무료 PRD 생성에도 AI 비용이 든다. 무료 생성은 계정당 3개까지이고, 다 쓰면 더 만들 수 없다(인터뷰는 무제한).

**미결 사항:** 사업자등록과 통신판매업 신고, 미사용 크레딧 환불 규정은 결제 오픈 전에 확인한다.

## 9. 비기능 요구사항

| 항목 | 요구사항 |
| --- | --- |
| 보안 | Anthropic·토스 키는 서버 환경변수에만 둔다. 브라우저 코드에 키가 노출되면 안 된다 |
| 데이터 접근 | 모든 테이블 RLS 적용, 크레딧·결제 변경은 서버에서만 |
| 비용 | 무료 PRD 생성 계정당 3개, 사용자당 분당 요청 제한. 월 AI 비용 알림 설정 |
| 속도 | 질문 3초 이내, 문서는 스트리밍으로 첫 글자 5초 이내 |
| 화면 | 모바일에서 인터뷰 가능(반응형). 결과 문서는 PC 사용 기준 |
| 개인정보 | 개인정보처리방침과 이용약관 페이지. 사용자 아이디어를 다른 사용자에게 노출하지 않음 |
| 오류 처리 | AI 응답 실패 시 자동 재시도 1회, 그래도 실패하면 "다시 시도" 버튼. 실패한 생성은 크레딧 차감 안 함 |

## 10. 클로드 코드 개발 순서

한 단계가 끝나고 브라우저에서 직접 확인한 뒤에만 다음 단계로 넘어간다. 각 단계 시작 전 클로드 코드에 "코드 쓰기 전에 계획부터 설명해"라고 붙인다.

**준비:** 이 문서를 Markdown으로 내보내 프로젝트 폴더의 `docs/PRD.md`로 저장한다. Supabase, Vercel, Anthropic Console, 토스페이먼츠(테스트) 계정을 만들어 둔다.

- [ ] **1. 프로젝트 생성과 규칙 파일**
  - 프롬프트: "docs/PRD.md를 읽고 Next.js(App Router, TypeScript, Tailwind, shadcn/ui) 프로젝트를 만들어. PRD 요약과 '한 번에 한 단계만, 수정 전 계획 설명'이라는 규칙을 담은 CLAUDE.md도 작성해."
  - 확인: `npm run dev`로 첫 화면이 뜬다.
